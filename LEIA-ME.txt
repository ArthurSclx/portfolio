ATUALIZAÇÃO VISUAL — LINHA DO TEMPO

O pacote atualiza apenas:
- index.html
- assets/css/style.css

A nova linha do tempo tem um título lateral que permanece visível no desktop enquanto os anos e os cartões passam pela tela. Cada marco aparece com uma animação suave quando entra na área visível. Em celulares, o layout se reorganiza em uma única coluna.

LOGOS
Adicione estes arquivos à pasta assets/img do seu projeto:
- assets/img/Newton.png
- assets/img/Espro.png
- assets/img/Santander.png

Use exatamente estes nomes, respeitando as letras maiúsculas e minúsculas. Se alguma logo não estiver pronta, o cartão mostra um monograma (NP, ES ou S) no lugar.

COMO APLICAR
1. Faça uma cópia de segurança dos arquivos atuais.
2. Extraia este ZIP em uma pasta temporária.
3. Copie o index.html extraído para a raiz da pasta local do repositório portfolio, substituindo o arquivo existente.
4. Copie assets/css/style.css para portfolio/assets/css/style.css, substituindo o arquivo existente.
5. Coloque as logos em portfolio/assets/img/.
6. Abra o site com Live Server e confira a seção Formação & Reconhecimentos rolando a página.
7. Para publicar no GitHub pelo terminal do VS Code, execute:
   git add index.html assets/css/style.css assets/img/
   git commit -m "Refina linha do tempo de formação"
   git push
